The current game art lives in `art/source/guest-building-strips` and `apps/web/public/guest-buildings`; the current choice sheet is `docs/images/near-estate-fifteen-building-choices-v2.png`.

The older `apps/web/public/illustrated` library was not moved because the independent owner preview and earlier building kit still read it. The archive is for visual comparison and rollback; game code does not load it.
