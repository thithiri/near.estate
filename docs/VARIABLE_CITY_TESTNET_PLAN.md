## Recommended approach

Upgrade the **existing testnet contract account** with an explicit, versioned storage migration, after pausing purchases and parking. This keeps player accounts, coin balances, cars, existing media history and the contract address. The old plot values have a fixed Borsh layout; changing `Plot` or `Contract` directly without a migration entry point would make stored values unreadable. The current `upgrade_testnet.rs` intentionally rejects such a layout change, so create a separate migration runner and keep that guard for ordinary upgrades.

Migration must use the final on-chain snapshot, not the guest mock as authority. For the two current holdings, move ownership and the complete deed state (rule and pending rule, building level, name, media approvals and proposals, cooldowns, storage reserve and recorded income references) to the mapped 2-unit destination. Check any plot-specific histories or indexer joins that cannot be rewritten; retain an immutable old-ID → new-ID alias for event/stats history. Do not silently move a player's purchased location if that player is no longer a project test account; obtain their explicit choice of an equal-width destination or provide a documented fresh testnet restart path.
