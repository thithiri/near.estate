## Supporting records (not re-checked by the script)

- **Hosted technical preview.** The production Compose stack on a single VPS served HTTPS, the web client, API and finalized-block indexer at [near.estate](https://near.estate). Its release probe matched the live code hash and recorded five roads, 100 plots and eight game-owned sites. The public probe was rerun successfully on 2026-11-14. It now runs commit `96e1343` from `main`, and `/api/health` reports the same revision. [`vps-release-2026-11-14.json`](deployments/vps-release-2026-11-14.json)
- **Human and agent game loops.** Two restricted car agents parked and collected, while a plot agent changed a curated building design; receipt checks matched signing keys and events, and all temporary grants and keys were revoked. A separate safeguard run rejected wrong-plot, over-budget, stale-preview and expired-grant calls. [`testnet-agent-pilot-2026-11-14.json`](deployments/testnet-agent-pilot-2026-11-14.json), [`testnet-agent-safeguards-2026-11-14.json`](deployments/testnet-agent-safeguards-2026-11-14.json)
- **Fuel and destination heart.** A disposable car spent ten fuel on a legal Market North park, checked in at Near & Far Burgers, collected with a separate two-coin `visit_bonus_paid` event, then refilled ten fuel for two coins. The test temporarily used a one-minute minimum and restored the normal ten-minute policy. [`testnet-heart-fuel-journey-2026-11-14.json`](deployments/testnet-heart-fuel-journey-2026-11-14.json)
- **Popup-free gameplay key.** On a disposable testnet contract, a restricted function-call key made allowed calls. Other methods, attached deposits and other receivers were blocked. The allowance ran out, and the key was revoked on-chain. [`testnet-gameplay-key.json`](deployments/testnet-gameplay-key.json)
- **Upgrades without data loss.** The current fuel-and-heart candidate passed an imported-state sandbox rehearsal, a recovery drill and a guarded code-only release. A finalized-block postcheck matched code `f32cff1a…`, 100 plots, 180 curbs, eight civic sites and an unpaused city while preserving the prior city state. [`runtime-upgrade-sandbox-f32cff1a48532d3c.json`](deployments/runtime-upgrade-sandbox-f32cff1a48532d3c.json), [`runtime-upgrade-drill-f32cff1a48532d3c.json`](deployments/runtime-upgrade-drill-f32cff1a48532d3c.json), [`runtime-upgrade-live-f32cff1a48532d3c.json`](deployments/runtime-upgrade-live-f32cff1a48532d3c.json), [`runtime-upgrade-postcheck-f32cff1a48532d3c.json`](deployments/runtime-upgrade-postcheck-f32cff1a48532d3c.json)

## Not done or known limits

- **Wallet signing in the browser.** No named wallet (Meteor, plus a second wallet) has yet completed a browser journey on desktop or phone. The on-chain journeys above were signed by scripts with testnet keys kept outside the repository.
- **Real phones.** Phone checks use emulated viewports in headless Chromium. Physical-device frame rate and GPU memory are unmeasured.
- **Test coverage of the live code.** Version-2 unit and near-workspaces sandbox tests cover three-unit curb parking, capped collection, stored meter terms after a rule change, owner tickets, bounded hearts and agent permissions. Hosted CI has passed app, contract and container jobs, and the signed journeys above exercise the shared testnet. This does not establish named-wallet browser signing or long-running agent behavior.
- **Moderator revocation.** The active-hash-preserving revocation fix is deployed on the shared testnet city. Moderator judgment and image hosting remain operator-controlled; a player cannot independently force publication of an image.
- **Advertiser statistics.** Impressions are client-reported estimates with per-session deduplication. They are not billing-grade.
- **Generated building art.** Paid, owner-prompted image generation is disabled. Curated illustrated assets are playable; the paid generation path has fake-provider tests but no verified real-provider purchase or publication.
- **The game economy.** Coins are nontransferable, nonredeemable testnet game points. Plots and cars are contract registries, not NFTs.
