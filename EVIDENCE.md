## Supporting records (not re-checked by the script)

- **Popup-free gameplay key.** On a disposable testnet contract, a restricted function-call key made allowed calls. Other methods, attached deposits and other receivers were blocked. The allowance ran out, and the key was revoked on-chain. [`testnet-gameplay-key.json`](deployments/testnet-gameplay-key.json)
- **Upgrades without data loss.** The revocation-fix candidate passed a read-only live-state sandbox pause, deployment, reopen and rollback, preserving all 381 storage entries and ten street-side views. The same WASM was then deployed to the shared testnet city through the guarded code-only runner. Its live pause/deploy/reopen journal preserves the complete state hash, and a finalized-block RPC postcheck confirms the new code, 100 plots, 180 curbs, seven civic sites, roles and unpaused state. [`runtime-upgrade-sandbox-ad148df441a41d1f.json`](deployments/runtime-upgrade-sandbox-ad148df441a41d1f.json), [`runtime-upgrade-drill-ad148df441a41d1f.json`](deployments/runtime-upgrade-drill-ad148df441a41d1f.json), [`runtime-upgrade-live-ad148df441a41d1f.json`](deployments/runtime-upgrade-live-ad148df441a41d1f.json), [`runtime-upgrade-postcheck-ad148df441a41d1f.json`](deployments/runtime-upgrade-postcheck-ad148df441a41d1f.json)
- **Event indexer.** It indexes only finalized blocks, then backfills and replays without double counting. [`testnet-event-source.json`](deployments/testnet-event-source.json), [`testnet-indexer-backfill.json`](deployments/testnet-indexer-backfill.json), [`testnet-contested-curb-indexed-post-upgrade.json`](deployments/testnet-contested-curb-indexed-post-upgrade.json)
- **Inspector bounds.** The inspector NPC is limited to one attempt per session and a global patrol window. [`testnet-inspector-journey.json`](deployments/testnet-inspector-journey.json)
- **Backups.** A backup and restore of the service database and images resumed the indexer cursor with zero duplicate events. [`testnet-shared-media-backup-restore.json`](deployments/testnet-shared-media-backup-restore.json)
- **Browser suite.** `npm run test:browser` runs 54 Playwright tests against the guest city; two more are skipped by default. They cover driving, parking, collecting, repair, tickets, tower fallback when every curb is full, map travel, cinema, burger stop, practice course and the building studio. Each runs at desktop, phone-landscape and phone-portrait viewport sizes. See [`tests/browser/`](tests/browser/).
- **Contract tests.** `npm run contract:test` runs the unit and near-workspaces sandbox tests. They cover settlement arithmetic, pay-once races, rule deadlines, tickets, inspector limits, pause and emergency repair.

## Not done or known limits

- **Wallet signing in the browser.** No named wallet (Meteor, plus a second wallet) has yet completed a browser journey on desktop or phone. The on-chain journeys above were signed by scripts with testnet keys kept outside the repository.
- **Real phones.** Phone checks use emulated viewports in headless Chromium. Physical-device frame rate and GPU memory are unmeasured.
- **Test coverage of the live code.** The version-2 runtime has direct unit tests for three-unit curb parking, capped collection, stored meter terms after a rule change, and owner ticket payout. A self-contained near-workspaces test deploys freshly built version-2 WASM, then signs registration, third-space parking and owner ticket transactions. It checks the 70% owner split, 30% burn, unauthorized ticket rejection and no duplicate payout. CI is configured to run both suites; that hosted run is pending. This focused sandbox test does not repeat the full migration rehearsal or a named-wallet browser journey.
- **Moderator revocation race on the live code.** The current testnet binary still rejects an active facade or logo takedown if an owner submits a replacement between the moderator's read and transaction. The source now permits revocation when the supplied revision is no later than the current one and the active content still matches exactly; local unit and WASM sandbox tests pass, and API reconciliation clears the canceled replacement. The candidate passed an imported-state sandbox upgrade, but a live deployment is still needed before it protects the shared testnet city.
- **Advertiser statistics.** Impressions are client-reported estimates with per-session deduplication. They are not billing-grade.
- **Generated building art.** Paid image generation is disabled. Facades are curated, and generated art has had fake-provider tests only.
- **The game economy.** Coins are nontransferable, nonredeemable testnet game points. Plots and cars are contract registries, not NFTs.
